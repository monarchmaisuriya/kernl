# Pick an agent

YourStack runs either its **own agent** (with your model keys) or an agent you already use:

| Agent | Uses |
| --- | --- |
| **YourStack** | Your API key for Anthropic, OpenAI, Google, DeepSeek, a local server, or any OpenAI-compatible service |
| **Claude Code** | Your Claude login, or an API key stored in YourStack |
| **Codex** | Your Codex login, or an API key |
| **OpenCode** | OpenCode's own setup (free models work without a login) |

Every edit and command asks you first, whichever agent you pick.
