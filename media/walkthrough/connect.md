# Connect it

- **kernl agent:** open **Manage providers**, pick a provider, and paste its API key. Keys are stored in VS Code's secret storage, never in settings.
- **Claude Code, Codex, OpenCode:** open **Agent logins**. "Log in in a terminal" runs the agent's own login; or store an API key for it.

The agent chip in the panel shows a warning when its agent still needs setup.
